# Security Policy

## Supported Versions

Elevate Research is currently under active development. Security updates are applied to the latest version of the website.

| Version | Supported |
|----------|-----------|
| Latest | ✅ |
| Older versions | ❌ |

---

## Reporting a Security Vulnerability

The security of Elevate Research is important to us.

If you believe you have discovered a security vulnerability, please report it responsibly by contacting us privately.

**Email:** security@elevateresearch.in

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Screenshots or proof of concept (if applicable)
- The affected page or feature
- Your browser and operating system

Please do **not** disclose the vulnerability publicly until it has been investigated and resolved.

---

## Response Process

Once a report is received, we will:

1. Acknowledge receipt of the report.
2. Investigate the issue.
3. Confirm whether the vulnerability is valid.
4. Develop and deploy an appropriate fix.
5. Notify the reporter once the issue has been resolved.

Response times may vary depending on the complexity of the issue.

---

## Scope

This policy applies to:

- The Elevate Research website
- Research publishing platform
- Community platform
- Authentication systems
- APIs (when introduced)
- Future mobile applications

---

## Out of Scope

The following are generally considered out of scope:

- Spam or phishing reports
- Social engineering
- Denial-of-Service (DoS/DDoS) testing
- Physical security issues
- Issues requiring access to user devices
- Reports based solely on outdated browser versions

---

## Responsible Disclosure

We appreciate responsible disclosure practices that help improve the security of the platform while protecting our users.

Thank you for helping keep Elevate Research secure.
